Qué hay detrás

Red + selección + contexto + seguimiento.

Tener contactos no significa tener relaciones activas. El valor aparece cuando existe una buena razón para iniciar la conversación.

1
Red Partimos de relaciones, perfiles, comunidad, expertos, partners y conversaciones que ya existen.
2
Selección No todo el mundo debe hablar con todo el mundo. Priorizamos perfiles y temas con lógica real.
3
Contexto Ronda, Foro, entrevista, mesa o sesión privada: creamos una razón concreta para entrar en conversación.
4
Seguimiento Cuando existe recorrido, la relación puede continuar hacia colaboración, partnership, oportunidad o negocio.
No juntamos gente. Diseñamos razones para que la gente adecuada hable.
